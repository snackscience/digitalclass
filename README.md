# 오늘의 배움 한 장 · SchoolKit

**AI 디지털 시대, 교육의 본질을 찾아서** 연수 후 선생님들이 배운 내용을 정리하는 모바일 웹앱입니다.

## 흐름
1. 학교명 · 이름 · 담당 학년 · 과목 입력
2. 가장 인상 깊은 내용 — 8개 TOPIC 중 1개 선택 + 이유(선택)
3. 수업에 적용해 보고 싶은 내용 — 1개 선택
4. 수업 적용 아이디어 작성 (적용 TOPIC 맞춤 수업 장면 예시 6개 중 선택 + 직접 작성)
5. AI 피드백 → 성찰 카드 **이미지 저장 · 제출**

## AI 피드백 모드
| 모드 | 설정 | 동작 |
|---|---|---|
| 기본 (설정 없음) | 없음 | 연수 내용 기반 응원 메시지 + 새로운 수업 아이디어, 이미지 저장 |
| Gemini AI | `gas/Code.gs` 배포 후 `index.html`의 `CONFIG.GAS_URL` 입력 | Gemini 응원 메시지·아이디어 + 구글 시트 응답 수집 + 드라이브 이미지 저장 |

Gemini 응답이 실패하면 자동으로 기본 모드 피드백으로 대체됩니다.
